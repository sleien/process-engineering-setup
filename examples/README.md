# Example projects

Open any `.wwtp.json` with **File → Open project…** in the toolbar, then click **▶ Simulate**.

| File | What it shows |
| --- | --- |
| `mabr-single-influent.wwtp.json` | The smallest runnable plant: one feed, one MABR. |
| `mabr-two-feeds.wwtp.json` | Two influents merging into one reactor (a `FlowUnifier`). |
| `ras-recirculation.wwtp.json` | Anoxic → aerated → clarifier with the RAS/WAS loop, the waste sized for a 15 d sludge age. |
| `ph-controlled-feed.wwtp.json` | An aerated CSTR fed a high-strength influent (COD 70.7 g/L, NH₄-N 1650 mg/L, alkalinity 209 mmol/L) **on pH**: the feed runs below pH 6.20 and stops above 6.25, holding its state in between. Nitrification pulls the pH down, the alkaline feed brings it back. Generated by `build_ph_controlled.py`, which documents the ASM1 fractionation of the analysis and its assumptions. |
| `ras-mlss-controller.wwtp.json` | The same plant with an **excess-sludge controller** on the clarifier: the WAS pump steps up while the MLSS in the aerated reactor climbs, holding it at 4100–4200 g/m³ instead of ~5400. The chart of what it set is under *Results → Controller outputs*. |
| `dynamic-decanting-dual-feed.wwtp.json` | A hand drawing of the Sumo plant — two headworks, parallel filter streets, a bypass basin. It is **not** the flowsheet Sumo simulates (see below); the sizing is nameplate data, not a tuned model. |
| `parallel-sbr-demo.wwtp.json` | **Start here.** The smallest plant that shows parallel streets, SBR cycles and a bypass: one feed split across two parallel SBR streets, staggered cycles, a COD/N bypass, a final clarifier. Three reactors, three recirculation loops. |
| `sumo-parallel-sbr.wwtp.json` | The **runnable** Sumo plant, on Sumo's own flowsheet: primary clarifier, two trickling filters in series, intermediate clarifier, two parallel SBR streets with ammonia-based aeration, a municipal overflow and a COD bypass. Matches the Sumo effluent within the reference's acceptance band (see below). Generated by `build_sumo_parallel.py`; a 21 d run takes ~11 min. |

## The Sumo comparison

`sumo_reference.json` holds the acceptance targets, read out of the stored steady state of
`SUMO_examples/Dynamic_Decanting_COD_Bypass_Flow_Min_Threshold_Fixed.sumo` (Sumo 4.3,
Sumo2 model). `sumo-parallel-sbr.wwtp.json` is the PeePyPoo/ASM1 model of the same plant.

Regenerate the project after changing any of its inputs:

```bash
python3 examples/build_sumo_parallel.py
```

The generator exists because the ASM1 fractionation of Sumo's total-COD/TKN influents has
to be computed rather than typed, and because the clarifier underflows follow from the
solids they remove.

**Run it with a 21 day horizon.** The industrial feed is a sampled weekly pulse stretched
across the simulated window, so a shorter run moves the pulses.
(`INDUSTRIAL_PULSE = False` in the generator swaps it for a weekly sinusoid of the same
mean, which has no such constraint — and no shock either.)

### The flowsheet

Read from the pipes in Sumo's `sumoproject.plant`:

```
municipal ─ screen ─┬─ switch, pumped 3000 m³/d ─┐
industrial ─ screen ┼────────────────────────────┴─ VKB ─┬─ TF 1+2 ─ TF 3+4 ─┐
                    │                                    └─ COD bypass ──────┤
                    └─ switch overflow ─────────────────── equalisation ─────┴─ ZKB
ZKB ─┬─ SBR street A (A1 + A2) ─┐
     └─ SBR street B (B1 + B2) ─┴─ aeration unit ─ effluent
```

The two feeds meet ahead of the primary clarifier (VKB, 88 % TSS removal) and run through
the two trickling filters **in series**. The municipal flow the switch does not pump, and
the COD bypass, go around the filters and meet their outflow ahead of the intermediate
clarifier (ZKB, 42 %), which feeds the two SBR streets. That raw municipal water is the
carbon the SBRs denitrify the filters' nitrate with.

An earlier version of this example followed the hand drawing instead, with two parallel
filter streets and no clarifiers. It matched Sumo only while the trickling filters were
modelled without oxygen, so they could not nitrify. Once they were ventilated, street A got
fully nitrified water with no carbon left, and effluent TN rose to 25.6 mg/L against
Sumo's 6.6.

### Where the model follows Sumo, and where it approximates

| Sumo | Here |
| --- | --- |
| Trickling filters, ventilated, bulk DO ~4 mg/L | Natural-draft aeration, backend default kLa 240 1/d |
| VKB / ZKB, `fXTSS_sludge` 0.88 / 0.42 | `primary_clarifier` units with the same `removal`; underflow from Sumo's sludge concentration target |
| SBRs: DO setpoint 1.5 mg/L while NH₄ > 1.5, aeration off below | Controller inside the react phase: off when `S_NH < 1.5`, otherwise bang-bang between 1.2 and 1.8 mg/L DO |
| Municipal switch: a PID holding COD/N = 3 in the filter feed | Fixed at Sumo's 3000 m³/d pumping target |
| COD bypass: switched on flow thresholds, 250 m³/d in normal operation | 250 m³/d, stepping to 500 while readily biodegradable COD in filters 1+2 is above 5 mg/L |
| Equalisation basin, variable volume | Drawn; the water passes straight through |
| SBRs alternately fed (A/B every 3 h) | Fed continuously, split ~4000 / 4500 m³/d, cycles staggered |

The bypass measures `S_S` rather than COD/N because the ratio is read in the filter's tank,
where the filter's own biomass counts towards both COD and N and keeps the ratio above 20
at all times.

### How many SBRs

The real plant has four SBRs (A1, A2, B1, B2). The generated project draws **one per
street**, each standing for that street's pair — same 4110 m³, same 7.4 h cycle, staggered
against the other street.

That is a solve-time decision, not a modelling one. Every settling unit carries an internal
return loop, and both `structural_simplify` and the stiff solve grow sharply with the number
of loops in one system; four SBRs plus two filters is six loops. Set
`SBRS_PER_STREET = 2` in `build_sumo_parallel.py` to draw all four — the staggers and the
flow split follow automatically — and expect a much longer run.

### Result

Final-week mean effluent of a 21 d run against `sumo_reference.json`:

| | Sumo | this model | ratio |
| --- | --- | --- | --- |
| TCOD | 41.03 mg/L | 47.50 mg/L | ×1.16 |
| TKN | 3.68 mg N/L | 3.57 mg N/L | ×0.97 |
| TN | 6.64 mg N/L | 6.51 mg N/L | ×0.98 |
| TSS | 22.24 mg/L | 24.97 mg/L | ×1.12 |
| TP | 3.83 mg P/L | — | not modelled (ASM1) |

Effluent NH₄ 1.84 and NO₃ 2.94 mg N/L. The reference's acceptance rule — within 2× on
TCOD, TKN and TP — holds for TCOD and TKN; TP cannot be reproduced at all. The SBRs' `f_ns`
was calibrated on the reference TSS (22.12 mg/L at the time); the other three are not
calibrated. These figures are from the run after the tanks' starting MLSS was made to mean
suspended solids (0.75 g TSS per g particulate COD), which changed the start-up, not the
plant: TN moved from 7.67 to 6.51, TSS from 22.1 to 25.0.

How the flowsheet and the controls moved TN, each a full 21 d run:

| Model | TN | NO₃ |
| --- | --- | --- |
| Hand drawing, filters without oxygen (the old example) | 9.68 | — |
| Hand drawing, filters ventilated | 25.61 | 24.04 |
| Sumo flowsheet, SBRs aerating the whole react phase | 14.35 | 11.57 |
| Sumo flowsheet, ammonia-based SBR aeration | 7.67 | 3.39 |
| … with the starting MLSS read as suspended solids | 6.51 | 2.94 |

Effluent oxygen comes out at ~5.5 mg/L instead of the 2.0 setpoint: the polishing tank
holds almost no biomass, so nothing consumes the oxygen and its controller has nothing to
regulate against.

### What this model can and cannot match

| Sumo target | Reproducible here |
| --- | --- |
| Effluent TCOD, TKN, TN, NH₄, NO₃ | Yes — these are what ASM1 is for. |
| Effluent TSS | Yes, through the SBRs' `f_ns` — the non-settleable solids in their decant, calibrated on the reference TSS. |
| Effluent **TP** | **No.** ASM1 has no phosphorus; matching TP needs ASM2d. |
| Effluent **temperature** | **No.** The reactor temperature is fixed at 20 °C. |
| SBR fill-and-draw level swings | No — the CSTR volume is constant. The cycle drives the *aeration*, and the tanks are staggered so the bank accepts flow continuously. |
| Trickling-filter biofilm profile | No — modelled as a completely mixed, ventilated tank that keeps its solids through an internal clarifier, not as a film with a depth profile. |
